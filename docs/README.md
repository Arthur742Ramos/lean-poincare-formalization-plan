# Documentation index

The documentation is divided by purpose so that current status, future plans,
publication state, and historical notes cannot be confused with one another.

## Current authorities

- [Current formalization status](status.md) is the source of truth for what is
  proved, conditional, supporting, open, or future.
- [Roadmap](roadmap.md) describes the mathematical path to the Poincaré
  conjecture.
- [Dependencies](dependencies.md) gives the critical path and parallel work
  boundaries.
- [Point-4 plan](point4/README.md) records the current local-existence gap and
  executable completion gate.

## Package documentation

- [Curvature package](../curvature/README.md) gives build commands and the
  supported package boundary.
- [Curvature package map](../curvature/docs/curvature-package.md) maps proved
  capability groups to source modules.

## Submission tracking

- [Palomar submission portfolio](palomar-submission-plan.md) records candidate
  boundaries and publication workflow state.

Submission state is independent of roadmap completion. A theorem can be proved
without being submitted, and a verified focused artifact does not imply that a
larger roadmap milestone is complete.

## Historical records

[Historical documentation](history/README.md) preserves long-form progress
logs and earlier package snapshots. Those files are useful for provenance,
theorem-name searches, and failed-approach archaeology; they are not current
status authorities.
